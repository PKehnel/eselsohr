# Contributing

Keep changes small and explain the user-visible problem. Run the checks in
[Testing](docs/TESTING.md) that exercise the affected behavior. Use synthetic
accounts and notes; never attach real member details, credentials or browser traces.

Preserve private-first creation, creator-only sharing controls, stable stored
IDs, legacy note paths and unsent drafts. Saved requires server acknowledgement.
Changes to queries, the schema or the worker need offline and upgrade checks.
Keep the light donkey interface accessible and respect reduced motion.

By submitting code you offer it under PolyForm Noncommercial 1.0.0; eligible
documentation and raster-art contributions use CC BY-NC 4.0. Keep existing
notices and identify third-party material and its license. Only contribute
material you can license. Describe AI-assisted artwork honestly and include
its origin and any source permissions; do not claim exclusive rights without
a basis. See [Licensing](docs/LICENSING.md).

Dependency updates need a clean install, audit and relevant behavior/delivery
checks. Review updates manually; no automatic merging or production deployment.
See [Security](SECURITY.md) for findings and dependency override rationale.
